# Object and Human Sensing Using Wi-Fi

## Project Overview

Object and Human Sensing Using Wi-Fi is a project that explores the use of Wi-Fi signals to detect objects and humans within an environment.

Instead of relying on traditional cameras or physical sensors, the project investigates how changes in wireless signal patterns can be analyzed to identify the presence of objects and humans without requiring direct visual observation.

## Project Objectives

- Explore how Wi-Fi signals can be used for object detection.
- Investigate human presence detection using Wi-Fi signals.
- Understand how objects and human movement affect wireless signal propagation.
- Analyze changes in Wi-Fi signal characteristics to identify activity within an environment.
- Develop a system that demonstrates the potential of Wi-Fi-based sensing.

## How It Works

Wi-Fi signals travel through an environment and interact with surrounding objects and people.

These interactions can cause changes in wireless signal characteristics, such as signal strength and channel information.

By analyzing these changes, the system aims to:
- Detect the presence of objects.
- Identify human presence.
- Recognize changes caused by human movement.
- Monitor activity within a designated environment.
